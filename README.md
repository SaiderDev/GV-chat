# Android mobile app: GV Chat

This is the source code for the Android mobile app: GV Chat. 


## How to make contributions?
Please read and follow the steps to use the app:
  1) Launch the app using the latest version of VS studio. Alternatively you can use Android studio IDE.
  2) The following extensions are required for VS studio launch: Android emulator launcher,Kotlin, extension pack for Java & gradle for Java
  3) Build an APK file and distribute to android devices for testing
  4) Alternatively you can launch an emulator on Android studio for testing
